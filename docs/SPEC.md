## 1. การตั้งปลุกพื้นฐาน
- ตั้งเวลาปลุก รองรับทั้ง 12 และ 24 ชั่วโมง
- ปลุกซ้ำตามวันในสัปดาห์ (preset: วันทำงาน / เสาร์–อาทิตย์ / ทุกวัน / เลือกเอง)
- ตั้งชื่อหรือป้ายให้แต่ละปลุก
- Toggle เปิด/ปิด
- แสดงเวลาที่เหลือก่อนปลุกดัง
- ปลุกครั้งเดียวตามวันที่ที่ระบุ
- Skip next (ข้ามการปลุกครั้งถัดไปครั้งเดียว)
- ปิดปลุกอัตโนมัติในวันหยุดนักขัตฤกษ์ไทย
- ปลุกเป็นรอบสำหรับคนทำงานกะ (เช่น ทำ 4 หยุด 2)

## 2. เสียงและการสั่น
- เสียงในตัวแอป / ริงโทนของเครื่อง / ไฟล์เพลงของผู้ใช้
- ระดับเสียงแยกรายปลุก
- เปิด/ปิดการสั่น และเลือกรูปแบบการสั่นได้
- ค่อย ๆ เพิ่มความดัง (fade-in)
- สุ่มเพลงจาก playlist
- เพลงจาก Spotify / YouTube Music (ดูข้อจำกัดในหัวข้อ 15)
- TTS อ่านเวลา สภาพอากาศ และนัดหมายประจำวัน (อ่านตามภาษาที่เลือกในแอป)

## 3. Snooze และการปิดปลุก
- กำหนดระยะ Snooze ได้
- จำกัดจำนวนครั้งที่ Snooze ได้
- ปิดปลุกอัตโนมัติถ้าดังนานเกินกำหนด
- ท่าทางควบคุม: คว่ำเครื่อง / กดปุ่มเสียง
- Snooze ยากขึ้นหรือสั้นลงในแต่ละครั้ง

## 4. Wake-up Missions
- โจทย์เลข (มีหลายระดับความยาก)
- เขย่าเครื่อง
- สแกน QR / barcode
- ถ่ายรูปวัตถุที่ลงทะเบียนไว้ (ML บนเครื่อง)
- เดินให้ครบจำนวนก้าว
- พิมพ์ประโยค / เกมความจำ
- "Are you awake?" ตรวจสอบซ้ำหลังปิดปลุก
- โหมดป้องกันการโกง

## 5. หน้าจอตอนปลุกดัง
- แสดงเต็มจอบน lock screen
- ปุ่มใหญ่ใช้ง่ายตอนเพิ่งตื่น
- แสดงเวลา วันที่ ชื่อปลุก และสภาพอากาศ
- พื้นหลังแบบเคลื่อนไหว (ตามธีมที่เลือก)

## 6. ฟีเจอร์นาฬิกาอื่น ๆ
- World Clock
- Timer (หลายตัวพร้อมกัน + preset)
- Stopwatch + Lap
- Bedside / Night clock mode

## 7. การนอนและสุขภาพ
- Bedtime reminder
- แนะนำเวลาตื่นตามรอบการนอน 90 นาที
- Smart alarm ปลุกในช่วงหลับตื้น
- สถิติการนอนและการ Snooze
- เสียงช่วยให้หลับพร้อม sleep timer
- Sunrise alarm (ความสว่างหน้าจอ + หลอดไฟผ่าน SmartThings)

## 8. Widget และการเข้าถึงด่วน
- Home screen widget (ทุกขนาด รองรับธีมและคู่สี)
- Quick Settings tile
- Nap / ตั้งปลุกด่วน
- Google Assistant / App Actions
- Wear OS (Galaxy Watch) → รายละเอียดในหัวข้อ 21

## 9. การตั้งค่าและการจัดการ
- โหมดมืด/สว่าง และ Material You (ดูหัวข้อ 12)
- ค่าเริ่มต้นสำหรับปลุกใหม่
- จัดกลุ่มปลุก
- Backup/Restore (ไฟล์ / Google Drive)
- Accessibility: TalkBack, ปรับขนาดตัวอักษร, high contrast

## 10. ความน่าเชื่อถือ
- `AlarmManager.setAlarmClock()`
- สิทธิ์ exact alarm / notifications / full-screen intent
- ตั้งปลุกใหม่หลัง reboot, อัปเดตแอป, เปลี่ยนเวลาหรือโซนเวลา
- ดังผ่าน alarm audio stream (ทะลุโหมดเงียบและ DND)
- เสียงสำรองถ้าไฟล์เพลงหายหรือเปิดไม่ได้
- หน้า self-test ทดสอบปลุก
- เตือนเมื่อแบตเตอรี่ต่ำก่อนนอน
- → รายละเอียดสำหรับ Samsung อยู่ในหัวข้อ 14

## 12. ระบบ Design / Theme (R2)

### ธีม (Design language)
แต่ละธีมไม่ได้เปลี่ยนแค่สี แต่เปลี่ยน **รูปทรง, เส้นขอบ, เงา, ระยะห่าง, animation และรูปแบบตัวเลขนาฬิกา** ทั้งหมด

| ธีม | ลักษณะ | สถานะ |
|---|---|---|
| **Minimal** | พื้นที่ว่างเยอะ เส้นบาง มุมโค้งนุ่ม ไม่มีเงา ตัวเลขบาง animation นุ่ม | ต้องมี |
| **Brutal** (Neo-brutalism) | เส้นขอบหนาสีดำ เงาทึบเยื้อง (hard offset shadow) มุมเหลี่ยม สีสด ตัวอักษรหนา/monospace ไม่มี gradient | ต้องมี |
| **Retro LCD** | ตัวเลข 7-segment มีเงาจาง ๆ ของ segment ที่ดับอยู่ เหมือนนาฬิกาดิจิทัลยุค 80–90 | ต้องมี |
| **Flip Clock** | ตัวเลขบนแผ่นพลิก มี animation ตอนเปลี่ยนนาที | ต้องมี |
| **Glass** | พื้นหลังเบลอโปร่งแสง ไล่สีนุ่ม ขอบสว่างบาง ๆ | ต้องมี |
| **Material You** | ใช้สีจาก wallpaper ของ One UI อัตโนมัติ | ต้องมี |
| **Terminal** | พื้นดำ ตัวอักษร monospace สีเขียวหรืออำพัน มีเคอร์เซอร์กะพริบ เหมือนหน้าจอ command line | ต้องมี |
| **Neon / Cyberpunk** | พื้นมืด เส้นและตัวอักษรเรืองแสง | ต้องมี |
| **Paper / Editorial** | สีกระดาษ font serif จัดหน้าแบบหนังสือพิมพ์ | ต้องมี |
| **Pixel / 8-bit** | ตัวอักษรและไอคอนแบบ pixel art เสียงปลุก chiptune | ต้องมี |
| **Analog Classic** | หน้าปัดเข็มนาฬิกา มีหลายแบบหน้าปัด | ต้องมี |
| **AMOLED Black** | ดำสนิท (#000) ประหยัดแบตบนจอ AMOLED ของ S24 Ultra เหมาะกับ Night clock | ต้องมี |

- (เสนอเพิ่ม) ผสมธีมได้ เช่น ใช้ธีม Minimal ทั้งแอป แต่หน้าปลุกดังใช้ Flip Clock
- ทุกธีมใช้ได้กับ widget, หน้าปลุกดัง, Night clock และหน้าปัดบน Galaxy Watch

### คู่สี (Color palettes)
- แต่ละธีมมีหลายชุดสี และแต่ละชุดมีทั้ง **light และ dark**
- ตัวอย่าง Minimal: Mono, Sand, Sage, Ocean, Rose
- ตัวอย่าง Brutal: Yellow/Black, Pink/Black, Lime/Purple, Blue/Orange, Red/Cream
- ทุกชุดต้องผ่าน contrast ratio ขั้นต่ำ WCAG AA
- (เสนอเพิ่ม) ผู้ใช้สร้างชุดสีเองได้
- (เสนอเพิ่ม) ตั้งธีมหรือสีแยกเฉพาะหน้าจอตอนปลุกดังได้
- Preview แบบ live ก่อนกดใช้
- Widget และหน้าปลุกเปลี่ยนตามธีมด้วย

## 13. ภาษาและ Font (R3, R4)

### ภาษา
- English (ค่าเริ่มต้น) และไทย
- เปลี่ยนในแอปได้ทันที และรองรับ per-app language ใน Settings ของ Android
- (เสนอเพิ่ม) เลือกแสดงปีเป็น ค.ศ. หรือ พ.ศ.
- (เสนอเพิ่ม) เลือกแสดงตัวเลขอารบิกหรือเลขไทย (๐–๙)

### Font
- ทุก font ที่ให้เลือกต้องมี **ทั้ง Latin และ Thai** หรือจับคู่ font ไทยสำรองให้อัตโนมัติ
- แยกได้ 2 ส่วน: **font ตัวเลขนาฬิกา** และ **font ข้อความทั่วไป**
- Font ที่ฝังมาในแอป (ตัวอย่าง, ทั้งหมดเป็น open license):
  - Sans: IBM Plex Sans Thai, Noto Sans Thai, Anuphan, Bai Jamjuree, Prompt, Kanit, Sarabun
  - Mono (เหมาะกับ Brutal): IBM Plex Mono / JetBrains Mono + Thai fallback
  - Display (ตัวเลขนาฬิกา): font บาง/หนาพิเศษ และ 7-segment
- (เสนอเพิ่ม) นำเข้า font เอง (.ttf / .otf)
- ปรับขนาดตัวอักษรได้ และเคารพค่า font size ของระบบ

## 14. ระบบป้องกันแอปถูกปิด (R6): Samsung One UI

### ข้อจำกัดที่ต้องรู้
- ถ้าผู้ใช้กด **Force stop** เอง Android จะลบปลุกทั้งหมดของแอปทิ้ง และไม่มีแอปไหนป้องกันได้ แอปทำได้แค่ตรวจพบในครั้งถัดไปที่เปิด แล้วตั้งปลุกใหม่ทันทีพร้อมเตือนผู้ใช้
- ถ้าแอปถูกใส่ใน **"Deep sleeping apps"** ของ Samsung ปลุกอาจไม่ดัง ต้องป้องกันไม่ให้เกิดสถานะนี้

### ชั้นป้องกันในตัวแอป
1. ตั้งปลุกด้วย `setAlarmClock()` ซึ่งระบบให้ความสำคัญสูงสุดและข้าม Doze ได้
2. ขอยกเว้น battery optimization (`REQUEST_IGNORE_BATTERY_OPTIMIZATIONS`)
3. Direct Boot aware: ปลุกดังได้แม้เครื่อง reboot แล้วยังไม่ได้ปลดล็อก (`LOCKED_BOOT_COMPLETED` + device-protected storage) ซึ่งสำคัญเพราะ Device care ของ Samsung มีโหมด auto-restart ตอนกลางคืน
4. Watchdog: งานตรวจสอบเป็นระยะ (WorkManager) ว่าปลุกยังถูกตั้งอยู่ครบ ถ้าหายให้ตั้งใหม่
5. ตรวจจับการถูก force stop หรือปลุกหาย แล้วแจ้งเตือนผู้ใช้
6. (ทางเลือก ผู้ใช้เปิดเอง) Foreground service พร้อม notification ถาวร เป็นชั้นป้องกันเพิ่ม แลกกับแบตเตอรี่เล็กน้อย

### Setup Wizard + Health Check สำหรับ Samsung
มีหน้าตรวจสถานะที่แสดง ✅/❌ ทีละข้อ และกดแล้วพาไปหน้าตั้งค่านั้นในเครื่องโดยตรง:
- Battery ของแอป = **Unrestricted**
- เพิ่มแอปใน **Never sleeping apps** (Device care → Battery → Background usage limits)
- ปิด **Put unused apps to sleep**
- ปิด **Pause app activity if unused**
- อนุญาต exact alarm, notifications และ full-screen notifications
- ล็อกแอปใน Recents (Keep open)
- ตรวจ App standby bucket ของแอป
- ทดสอบปลุกจริงหลังตั้งค่าเสร็จ

> ⚠️ ชื่อเมนูและตำแหน่งการตั้งค่าใน One UI 9 / Android 17 ต้องตรวจกับเครื่องจริงก่อนพัฒนา เพราะ Samsung เปลี่ยนบ่อย

## 19. Changelog, What's New และ AI Disclaimer

- **เวอร์ชันแอป** (versionName + versionCode)
- **วันที่ build** (ใส่อัตโนมัติตอน build)
- ตัวอย่างข้อความ:
  - EN: "This app was developed with the assistance of AI (model: {model}). Version {version}, built {date}."
  - TH: "แอปนี้พัฒนาโดยใช้ AI ช่วย (โมเดล: {model}) เวอร์ชัน {version} build เมื่อ {date}"

## 21. แอป Galaxy Watch (Wear OS) (R8, R12)

อุปกรณ์เป้าหมาย: **Galaxy Watch5** (Wear OS) มีเซนเซอร์วัดการเคลื่อนไหวและอัตราการเต้นหัวใจครบสำหรับ Smart alarm
- ต้องตรวจเวอร์ชัน Wear OS / One UI Watch ที่ติดตั้งอยู่บนนาฬิกาจริงก่อนเริ่มพัฒนา เพื่อเลือก API ให้ตรง
- แบตของ Watch5 ไม่ได้ใหญ่มาก จึงให้ Smart alarm อ่านเซนเซอร์เฉพาะช่วงหน้าต่างเวลาก่อนปลุก (เช่น 30–45 นาที) ไม่ใช่ทั้งคืน

- แสดงปลุกบนนาฬิกา **สั่นที่ข้อมือ** และกด Snooze หรือปิดจากนาฬิกาได้
- ตั้งค่า: ดังพร้อมกันทั้งสองเครื่อง / ดังเฉพาะนาฬิกา (ปลุกเงียบไม่รบกวนคนข้าง ๆ) / ดังเฉพาะโทรศัพท์
- ซิงก์ปลุกระหว่างโทรศัพท์กับนาฬิกาผ่าน Wearable Data Layer โดยไม่ต้องใช้อินเทอร์เน็ตหรือ backend
- ปลุกบนนาฬิกายังทำงานได้แม้โทรศัพท์อยู่ไกลหรือแบตหมด
- **Smart alarm**: ใช้เซนเซอร์การเคลื่อนไหวและอัตราการเต้นหัวใจของนาฬิกาตรวจช่วงหลับตื้น แล้วปลุกภายในหน้าต่างเวลาที่ตั้ง
- **Mission บนนาฬิกา**: โจทย์เลขบนจอนาฬิกา หรือยกข้อมือ/เขย่าให้ครบจำนวนครั้ง
- **Tile**: ดูปลุกถัดไป เปิด/ปิด และตั้ง Nap ด่วน
- **Complication**: แสดงเวลาปลุกถัดไปบนหน้าปัดนาฬิกา
- Timer และ Stopwatch บนนาฬิกา ซิงก์กับโทรศัพท์
- ใช้ธีมและคู่สีเดียวกับแอปบนโทรศัพท์
- ต้องมีระบบกันถูกปิดบนนาฬิกาด้วย เพราะนาฬิกามีระบบประหยัดแบตของตัวเอง

## 22. การติดตั้งแบบ Sideload (R7)

ผลดีที่ได้จากการไม่ลง Play Store:
- ใช้สิทธิ์ที่ Play จำกัดไว้ได้เต็มที่ เช่น ขอยกเว้น battery optimization โดยตรง และ `USE_EXACT_ALARM`
- ไม่ต้องทำตามนโยบายและขั้นตอนรีวิวของ Play

สิ่งที่ต้องเตรียม:
- **Samsung Auto Blocker** (มีใน One UI 6 ขึ้นไป) บล็อกการติดตั้งแอปจากนอก Store ต้องปิดชั่วคราวตอนติดตั้งหรืออัปเดต (Settings → Security and privacy → Auto Blocker)
- ติดตั้งด้วยไฟล์ APK หรือผ่าน ADB
- แอปบน Galaxy Watch ต้องติดตั้งผ่าน ADB แบบ Wi-Fi (เปิด Developer options บนนาฬิกา)
- **เก็บ signing key ไว้ให้ดี** ถ้าทำหาย จะอัปเดตทับแอปเดิมไม่ได้ ต้องถอนการติดตั้ง ซึ่งทำให้ปลุกและการตั้งค่าหาย (ยกเว้นได้ backup ไว้)
- ไม่มีระบบอัปเดตอัตโนมัติ: อัปเดตด้วยการติดตั้ง APK ใหม่ทับ แล้ว What's New จะแสดงเอง
- (เสนอเพิ่ม) Backup อัตโนมัติก่อนอัปเดตทุกครั้ง

## 23. SmartThings Integration (R13)

ฟีเจอร์ที่ใช้ SmartThings:
- **Sunrise alarm**: ค่อย ๆ เพิ่มความสว่างและปรับสีไฟจากโทนอุ่นไปโทนขาว ภายในเวลาที่ตั้งก่อนปลุก (เช่น 15–30 นาที)
- **สั่ง Scene ตอนปลุกหรือตอนปิดปลุก** เช่น เปิดไฟห้องนอน เปิดม่าน หรือเปิดเครื่องชงกาแฟ (ถ้าเป็นอุปกรณ์ SmartThings)
- **Bedtime**: ค่อย ๆ หรี่ไฟลงเมื่อถึงเวลาเข้านอน
- เลือกอุปกรณ์หรือ Scene แยกเป็นรายปลุกได้
- ถ้าเชื่อมต่อ SmartThings ไม่ได้ (ไม่มีเน็ตหรือ token หมดอายุ) **ปลุกต้องดังตามปกติ** แล้วแจ้งเตือนว่าสั่งไฟไม่สำเร็จ

วิธีเชื่อมต่อ (ไม่ต้องมี backend):
- แอปเรียก SmartThings cloud API โดยตรงจากโทรศัพท์
- ⚠️ **ต้องตรวจก่อนพัฒนา:** เท่าที่ผมทราบ Samsung เปลี่ยนให้ Personal Access Token ที่สร้างใหม่หมดอายุภายใน 24 ชั่วโมง ถ้ายังเป็นแบบนั้น จะใช้ token แบบนี้ในแอปที่ต้องทำงานทุกเช้าไม่ได้ ต้องลงทะเบียนแอปแบบ OAuth ผ่าน SmartThings CLI แทน ซึ่งได้ refresh token มาต่ออายุเองบนเครื่อง และยังไม่ต้องมี backend
- เก็บ token แบบเข้ารหัสด้วย Android Keystore
- หน้า Health Check (หัวข้อ 14) เพิ่มรายการตรวจสถานะการเชื่อมต่อ SmartThings
